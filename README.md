# 🏥 Hospital Management System

A desktop-based Hospital Management System built using **Java Swing, JDBC, and SQLite**.

This application helps clinics and small healthcare facilities manage patients, doctors, appointments, billing, pharmacy records, reports, and other daily operations from one desktop application.

## ✨ Features

- 🔐 Login System
- 📊 Dashboard
- 👤 Patient Management
- 👨‍⚕️ Doctor Management
- 📅 Appointment Management
- 💳 Billing Management
- 🧾 PDF Invoice Generation
- 💊 Pharmacy & Medicine Management
- 📈 Reports
- ⚙️ Settings
- 💾 SQLite Database
- 📴 Offline Operation
- 🖥️ Standalone Windows Application

## 🛠️ Technologies

- **Java 21**
- **Java Swing**
- **JDBC**
- **SQLite**
- **iText PDF**
- **IntelliJ IDEA**
- **Git & GitHub**
